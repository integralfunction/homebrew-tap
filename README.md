# Integralfunction Tap

## How do I install these formulae?

`brew install integralfunction/tap/<formula>`

Or `brew tap integralfunction/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "integralfunction/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
